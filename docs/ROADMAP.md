# Roadmap — jilva-rs

No dates. Stages move when the work is honestly done.

## Stage 0 — Foundation (now)

- [x] Org profile and community files (`jilva-co/.github`)
- [x] Repo vision (this repo's README)
- [ ] RFC process published (`docs/RFC/README.md` + template)
- [ ] RFC-1: scope and non-goals
- [ ] RFC-2: component model
- [ ] RFC-3: theming

## Stage 1 — Prototype (later)

- Throwaway branch to test RFC ideas against reality
- Not published to crates.io; may be discarded entirely
- Success criterion: RFCs survive contact with code, or get rewritten

## Stage 2 — Alpha `0.1.0` (later)

- Minimal core: render loop, layout, theming, essential widgets
- `cargo add jilva` works; docs site section; examples folder
- Breaking changes expected through `0.x`

## Stage 3 — Beyond

- `1.0` only when the API is stable and proven in real apps
- Sibling languages (`jilva-go`, `jilva-ts`) start only after Rust alpha is genuinely usable

## Milestones (GitHub)

- `Foundation` — Stage 0 items
- `RFC-1 scope`, `RFC-2 components`, `RFC-3 theming`
- `v0.1-alpha` — created when Stage 1 begins, not before
